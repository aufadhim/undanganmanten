# Engine Immersia

- `rooms/RoomsEngine.jsx`: engine 1, 13 template.
- `book/BookEngine.jsx`: engine 2, 13 template.
- `landscape/LandscapeEngine.jsx`: engine 3, 14 template.
- `shared/ImmersiaHost.jsx`: jembatan editor/runtime dan komponen interaksi bersama.
- `shared/adapter.js`: pemetaan data undangan ke scene pack.

Runtime browser berada di `frontend/public/templates/engines/` dengan nama folder yang sama. Konfigurasi sumber template berada di `shared/template-scenes/`. Panduan lengkap: `docs/IMMERSIA_ENGINES.md`.
