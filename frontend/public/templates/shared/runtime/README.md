# Runtime umum Immersia

Dipakai lintas engine; jangan menyimpan konfigurasi atau aset khusus template di sini.

Engine 1 dan 3 berbagi renderer dan app dasar. Engine 2 mempertahankan renderer/navigasi buku sendiri. Semua engine berbagi konfigurasi, musik, bridge editor, sapuan baca, serta CSS dasar di folder ini.

Utilitas fitur lain berada satu tingkat di atas (`shared/`): tipografi, galeri, profil, hadiah, dan RSVP. Panduan struktur: `docs/IMMERSIA_ENGINES.md`.
