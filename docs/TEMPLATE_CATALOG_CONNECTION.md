# Penyambungan katalog 34 template

34 paket baru didaftarkan sebagai Immersia, bersama enam template Immersia sebelumnya. Eternal, Nawasena, dan Seraya tetap berada di Signature: total 43 pilihan, termasuk 40 Immersia.

Metadata kartu: `frontend/src/config/expandedThemes.js`. Nama sementara mengikuti judul konfigurasi masing-masing paket. Thumbnail memakai ilustrasi latar lokal yang sudah tersedia; tidak membuat gambar tambahan.

Pratinjau memuat komponen setiap paket secara lazy melalui PhonePreview. Allowlist dashboard, mode coba, admin dan server diperluas. Preset warna/font mengikuti sumber paket engine masing-masing. Kontrol ilustrasi, susunan blok, posisi penutup, dan pengiriman ilustrasi milik pengguna di server mengenali ID baru. Pilihan undangan pertama memakai katalog yang sama.

Bingkai foto bawaan sementara memakai bingkai template sumber engine; bukan ornamen khusus baru per budaya. Upload bingkai tetap dapat digunakan. Ini belum tahap pembuatan desain bingkai tambahan.

Tidak menjalankan testing, build, pemeriksaan browser, migrasi database atau deployment. Perubahan ada pada sumber proyek lokal; server yang tidak memuat ulang sumber perlu dimulai ulang agar daftar preset baru terbaca. Status authored bukan jaminan semua komposisi sudah lolos tinjauan visual.

## Kelompok katalog

Immersia tetap menjadi metadata koleksi/jenis pengalaman, bukan satu filter berisi 40 pilihan. Filter visual: Nusantara (18), Sakral (4), Asia (2), Eropa (4), Botanical (2), Klasik (5), Playful (5). Signature (3) tetap terpisah. Pengelompokan tidak mengubah engine atau ID template.
