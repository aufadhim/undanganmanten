# Prompt siap dikirim ke AI berikutnya

Saya melanjutkan proyek UndanganManten. Arsip terlampir berisi source kerja engine undangan, aset contoh, lab preview, dan panduan. Ekstrak/buka sebagai workspace. Baca `docs/handoff/START_HERE.md`, `ENGINE_MAP.md`, `DESIGN_CONTRACT.md`, dan `NEW_TEMPLATE_WORKFLOW.md` sebelum mengubah kode.

Tugas awal: jalankan template-lab, pahami perbedaan engine 1 (ruang), engine 2 (masuk buku), dan engine 3 (satu dunia landscape). Gunakan template yang ada sebagai implementasi acuan, jangan membuat ulang mesin dari nol. Pertahankan React wrapper/adapter dan shared components untuk musik, galeri/lightbox, RSVP, hadiah, typography, dan frame.

Brief template baru akan saya berikan berikutnya: nama/tema budaya atau suasana, engine pilihan, palet, elemen landmark, dan referensi. Jika belum ada brief, jelaskan kesiapan dan minta brief tersebut. Jangan langsung mengubah template lama.

Ketika brief sudah diberikan: buat art pack cat air/canvas yang konsisten, konfigurasi posisi/depth/kamera, animasi cover dan ambience, lalu integrasikan ke katalog aktif dan CMS. Jangan hanya membuat mockup atau menaruhnya di sandbox saja. Jika tool image generation tidak tersedia, jelaskan aset yang belum tersedia dan siapkan manifest/prompt aset; jangan menyatakan sudah menghasilkan ilustrasi yang belum dibuat.

Penting: tema harus terasa sebagai satu dunia dengan perjalanan kamera, bukan slide PPT/Prezi. Tidak boleh meregangkan gambar. Skala manusia harus masuk akal terhadap jalan/pohon/properti, kaki menapak. Teks memakai sapuan ivory lembut dengan tepi blur secukupnya. Warna watercolor tidak terlalu tajam. Cover tetap hidup setelah intro selesai. Prioritaskan HP portrait.

Jangan membaca atau meminta key lewat chat. Jangan mengakses/mengubah database produksi untuk uji tema. Potret personal tidak ada di paket; gunakan karakter contoh. Jalankan tes yang relevan, build, lalu cek visual HP dan desktop, cover sampai penutup serta kembali ke sampul. Laporkan file yang diubah, hasil tes, dan keterbatasan yang benar-benar ada. Jangan mengklaim tes visual bila belum dilakukan.
